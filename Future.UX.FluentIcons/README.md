# Future.UX.FluentIcons
This project provides a collection of Fluent Icons for use in .NET applications. It is designed to be compatible with .NET Standard 2.0, ensuring broad usability across different .NET implementations.
### Features
- A comprehensive set of Fluent Icons.
- Easy integration into .NET Standard 2.0 projects.
- Lightweight and efficient.
- Open source and community-driven.
- Supports .NET Standard 2.0, making it compatible with a wide range of .NET applications.
- Active community support and contribution opportunities.
- Cross-platform compatibility.

### Installation
You can install the Future.UX.FluentIcons package via NuGet Package Manager:

```INSTALL-PACKAGE Future.UX.FluentIcons```

Or via the .NET CLI:

```dotnet add package Future.UX.FluentIcons```
